# go-lthash

Package **lthash** implements LtHash — a homomorphic (multi-)set hash — as used by ATProto spaces, for the Go programming language.

## Documention

Online documentation, which includes examples, can be found at: http://godoc.org/github.com/reiver/go-lthash

[![GoDoc](https://godoc.org/github.com/reiver/go-lthash?status.svg)](https://godoc.org/github.com/reiver/go-lthash)

## Import

To import package **lthash** use `import` code like the follownig:
```
import "github.com/reiver/go-lthash"
```

## Installation

To install package **lthash** do the following:
```
GOPROXY=direct go get https://github.com/reiver/go-lthash
```
